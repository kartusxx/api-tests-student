## Запуск тестов

1. Установите любое IDE для разработки: [Jetbrains GoLand](https://www.jetbrains.com/ru-ru/go/) (Платное или по студенческой лицензии), [VS Code](https://code.visualstudio.com/) (бесплатное).
2. Установите [Git](https://git-scm.com/install/) на компьютер
3. [Установите](https://go.dev/doc/install) Go версии 1.25.1
4. [Настройте](https://docs.github.com/ru/authentication/connecting-to-github-with-ssh) доступ к своему Github-аккаунту
   по SSH-ключу.
5. Склонируйте себе репозиторий: `git clone <путь к вашему репозиторию>`
6. Подтяните необходимые зависимости через команду в корне проекта:

```bash
   go mod tidy
```

7. В файле `.env.override` (создайте его в корне, если нет) выставьте правильные значения для переменных окружения:

```
TEST_LOGIN=your_login
TEST_PASSWORD=your_password
```

8. Для запуска всех тестов достаточно выполнить команду в корне проекта:

```bash
  go test -v ./...
```

9. Отдельный пакет с тестами можно запустить командой:

```bash
  go test -v ./tests/scenarios/myAdvertisement/
```

## Тестовые сценарии

| Пакет | Что проверяется |
|---|---|
| `tests/scenarios/advertisementSearch` | Поиск объявления по подстроке в названии (начало, середина, конец, разные регистры); объявление создаётся и удаляется самим тестом |
| `tests/scenarios/createAdvertisement` | Создание объявления: позитивный сценарий (проверка по ID, в поиске и фотографий), негативные сценарии (пустой title, отрицательная цена, слишком длинный title, нет фото, больше 3 фото, нет токена и неверный токен) |
| `tests/scenarios/favorites` | Избранное: добавление и удаление, исчезновение объявления из избранного после его удаления, несуществующий `ad_id`, запросы без авторизации, повторное добавление (409), добавление своего объявления (403) |
| `tests/scenarios/myAdvertisement` | Получение собственных объявлений. Использует аккаунт из `.env.override`: в нём должно быть хотя бы одно объявление с фотографией, иначе тест упадёт |

Запуск отдельного сценария:

```bash
go test -v ./tests/scenarios/createAdvertisement/
go test -v ./tests/scenarios/favorites/
```

Рекомендуемый запуск всех тестов: `go test -v ./...`. Если сервер перегружен и отвечает 503, можно запускать пакеты по очереди: `go test -p 1 ./...`.

## Особенности тестов

- Тесты создают свои данные сами (объявления создаются через API) и удаляют их после завершения, поэтому их можно запускать любое количество раз подряд.
- Пользователей для сценариев создания объявления и избранного тесты регистрируют автоматически со случайным email вида `autotest_<число>@gmail.com`, ничего настраивать не нужно. Это изолирует новые тесты от основного аккаунта из `.env.override`, чтобы они не мешали тесту `myAdvertisement` при одновременном запуске пакетов.
- Объявление можно добавить в избранное только чужое, поэтому владелец объявления и пользователь, добавляющий его в избранное, - два разных зарегистрированных пользователя.
- Если сервер временно отвечает `503 Service Unavailable`, HTTP-клиент тестов повторяет запрос до 8 раз с нарастающей паузой (`internal/helpers/api-runner/retry.go`).
- Не покрыт лимит в 50 избранных объявлений на пользователя (ответ 400): для этого пришлось бы создавать 51 объявление, что сильно замедляет прогон и засоряет сервер.
- Файл `.env.override` содержит логин и пароль (он указан в `.gitignore`).

## Логирование

Для включения логирования request/response в консоль: выставьте переменную окружения `DEBUG=true` в
`.env.override`

## Запуск линтера

1. Установить приложение [golangci-lint](https://golangci-lint.run/docs/welcome/install/local/)
2. Запуск линтера (из корня репозитория):

```bash
  golangci-lint run
```
